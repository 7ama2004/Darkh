# Example Flashcard

This is an example flashcard showing how to use the Darkh SRS plugin.

## Inline Cloze Example

The capital of France is s;Paris;.

The formula for water is s;H₂O;.

Einstein developed the theory of s;relativity; in s;1905;.

## Multiline Cloze Example

What are the three states of matter?

1. Solid

e;

s;

e;

## Usage Notes

- Use **Toggle review view** command to start reviewing
- Press **Space** (or your configured hotkey) to reveal each cloze
- After all clozes are revealed, rate with **1** (Again), **2** (Hard), **3** (Good), or **4** (Easy)
- Scheduling data will be automatically added to frontmatter
- You can edit the note even while in Review View

## Tips

- Keep questions focused and atomic
- Use inline clozes for single words or short phrases
- Use multiline clozes for lists or longer explanations
- Don't nest clozes (not supported)
- File organization matters - use folders and meaningful names
